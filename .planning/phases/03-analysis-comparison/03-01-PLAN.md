Output: ExperimentComparator class with three comparison methods (by IDs, by group, by filter), export methods (to_csv, to_json, to_excel), and insights generation (clustering, correlation, outliers).

    Create mlflow_tracking/comparison.py with ExperimentComparator class:

    1. **Constructor**: Initialize MlflowClient, set default tracking_uri from config
    2. **compare_by_ids(run_ids, as_dataframe=True)**: Compare runs by explicit run IDs
       - Fetch runs using client.get_run(run_id) for each ID
       - Extract params, metrics, tags, metadata for each run
       - Return DataFrame if as_dataframe=True, else list of dicts
       - Auto-sort by primary metric (val.rmse ascending)

       - Return same format as compare_by_ids
       - Return empty DataFrame/dict if group doesn't exist

    4. **compare_by_filter(filter_string, max_results=100, as_dataframe=True)**: Compare runs matching MLflow filter
       - Use mlflow.search_runs() with filter_string parameter
       - Support MLflow filter syntax (metrics, params, tags)
       - Return same format as compare_by_ids
       - Raise ValueError if filter_string is empty

    All methods should:
    - Include columns: run_id, experiment_id, params.*, metrics.*, tags.*, start_time, status
    - Handle varying columns between runs (not all runs have same params/metrics)
    - Include failed runs with status="FAILED" and NaN for missing metrics
    - Use wide format: rows=experiments, columns=params/metrics/tags

    Use pandas for DataFrame operations. Return type controlled by as_dataframe parameter.

<task type="auto">
  <name>Create insights generation methods</name>
  <files>mlflow_tracking/comparison.py</files>
  <action>
    Add to ExperimentComparator class:

    1. **cluster_runs(runs_df, n_clusters=None, features='auto')**: K-means clustering of experiment results
       - Input: DataFrame from compare_by_* methods
       - Features: All metric columns if 'auto', else list of column names
       - n_clusters: Use elbow method if None (heuristic: min(5, len(runs_df)//2))
       - Use sklearn.cluster.KMeans with random_state=42 for reproducibility
       - Return dict with:
         - 'cluster_labels': array of cluster assignments
         - 'cluster_centers': array of cluster centers
         - 'inertia': within-cluster sum of squares
         - 'n_clusters': number of clusters used
       - Handle NaN values by filling with column mean before clustering
       - Raise ValueError if fewer than 2 runs

    2. **correlate_params(runs_df, method='pearson', threshold=0.5)**: Correlation analysis between params and metrics
       - Input: DataFrame from compare_by_* methods
       - Compute correlation matrix between all numeric params and metrics
       - Filter to show only correlations with abs(value) >= threshold
       - Return DataFrame with columns: ['param', 'metric', 'correlation']
       - Sort by absolute correlation descending
       - Support method='pearson' (default) or 'spearman'
       - Handle NaN by dropping rows with missing values

    3. **find_outliers(runs_df, method='zscore', threshold=3.0)**: Identify outlier experiments
       - Input: DataFrame from compare_by_* methods
       - Method='zscore': Use scipy.stats.zscore on metrics, flag |z| > threshold
       - Method='iqr': Use IQR method (Q1 - 1.5*IQR, Q3 + 1.5*IQR)
       - Return dict with:
         - 'outlier_runs': list of run_ids flagged as outliers
         - 'outlier_scores': dict of run_id -> outlier score
         - 'method': method used
         - 'threshold': threshold used
       - Analyze only metric columns (not params or tags)
       - Handle NaN by dropping before analysis

    All methods should:
    - Work with DataFrame input from compare_by_* methods
    - Use scikit-learn for clustering (KMeans)
    - Use scipy for z-score if available, else implement manually
    - Return simple dict/DataFrame results (not complex objects)
    - Include clear docstrings with examples
  </action>

    - cluster_runs() returns cluster labels for each run
    - correlate_params() returns correlation DataFrame sorted by |correlation|
    - find_outliers() returns list of outlier run_ids
    - All methods handle NaN values gracefully
    - All methods work with DataFrame from compare_by_ids()
  </verify>
