    Implement InsightsGenerator class in insights_generator.py:

    - __init__(self, tracking_uri: Optional[str] = None)
      Initialize MLflow client and ExperimentComparator instance
      Store comparator for use in insights generation

    - _check_normality(self, data: np.ndarray, alpha: float = 0.05) -> Tuple[bool, float]
      Check if data is normally distributed using Shapiro-Wilk test:
      * Use scipy.stats.shapiro(data) for normality test
      * Return (is_normal, p_value) tuple
      * is_normal = True if p_value > alpha (fail to reject null hypothesis)
      * Handle small samples (<20) with warning (use Mann-Whitney U instead)

    - perform_statistical_test(
        self,
        group1: np.ndarray,
        group2: np.ndarray,
        alpha: float = 0.05,
        test_type: str = "auto"
      ) -> Dict[str, Any]
      Perform statistical significance test between two groups:
      * If test_type is "auto":
        - Check normality of both groups using _check_normality()
        - If both groups are normal: use scipy.stats.ttest_ind(group1, group2)
        - If either group is non-normal: use scipy.stats.mannwhitneyu(group1, group2, alternative='two-sided')
      * If test_type is "ttest": use scipy.stats.ttest_ind() directly
      * If test_type is "mannwhitney": use scipy.stats.mannwhitneyu() directly
      * Calculate effect size using _calculate_effect_size()
      * Return dict with keys:
        - test_type: str (name of test used)
        - statistic: float (test statistic)
        - p_value: float (significance p-value)
        - significant: bool (p_value < alpha)
        - effect_size: float (Cohen's d)
        - effect_size_interpretation: str (small/medium/large)
        - mean_group1: float
        - mean_group2: float
        - improvement_pct: float ((mean_group2 - mean_group1) / mean_group1 * 100)

    - _calculate_effect_size(self, group1: np.ndarray, group2: np.ndarray) -> float
      Calculate Cohen's d effect size:
      * Compute pooled standard deviation:
        pooled_std = sqrt(((n1-1)*var1 + (n2-1)*var2) / (n1+n2-2))
      * Compute Cohen's d: (mean1 - mean2) / pooled_std
      * Return Cohen's d value
      * Handle edge case: return 0 if pooled_std is 0 (identical groups)

    - _interpret_effect_size(self, cohens_d: float) -> str
      Interpret Cohen's d effect size:
      * If abs(cohens_d) < 0.2: return "negligible"
      * If abs(cohens_d) < 0.5: return "small"
      * If abs(cohens_d) < 0.8: return "medium"
      * Else: return "large"
      * Reference: Cohen (1988) conventions

    - _generate_recommendation(
        self,
        p_value: float,
        effect_size: float,
        improvement_pct: float,
        alpha: float = 0.05
      ) -> str
      Generate actionable recommendation from statistical results:
      * If p_value >= alpha:
        - Return "No significant difference detected. Collect more data or refine experiment design."
      * If abs(effect_size) < 0.2:
        - Return "Significant but negligible effect size. Consider practical significance."
      * If abs(effect_size) < 0.5:
        - Return "Significant small effect. Consider cost-benefit trade-offs."
      * If abs(effect_size) < 0.8:
        - Return "Significant medium effect. Recommended for deployment."
      * Else:
        - Return f"Significant large effect ({improvement_pct:.1f}% improvement). Strongly recommended for deployment."

    Follow scipy.stats best practices:
    - Check assumptions (normality) before choosing test
    - Use two-sided tests by default (more conservative)
    - Handle small samples with warnings
    - Use Cohen's d for effect size (standard for t-tests)
    - Log which test was used for reproducibility

    - generate_insights(
        self,
        run_ids: List[str],

        alpha: float = 0.05,

      * Use self.comparator.compare_by_ids(run_ids) to fetch run data
      * Extract metric values: df[f'metrics.{metric}'].values
      * If group_by is provided:
        - Group runs by group_by parameter (e.g., "params.learning_rate")
        - Perform pairwise comparisons between groups
        - Use perform_statistical_test() for each comparison
        - Generate insights per group comparison
      * If group_by is None (overall comparison):
        - Find best run: df.loc[df[f'metrics.{metric}'].idxmin()]
        - Compare all runs to best run using perform_statistical_test()
        - Generate overall insights
      * Compute summary statistics:
        - mean_metric: float
        - std_metric: float
        - min_metric: float (best)
        - max_metric: float (worst)
        - range_metric: float (max - min)
      * Generate recommendation using _generate_recommendation()
      * Return dict with keys:
        - status: str ("success" or "insufficient_data")
        - best_run: str (run_id)
        - best_metric: float
        - summary_statistics: dict (mean, std, min, max, range)
        - statistical_tests: list of dicts (one per comparison)
        - overall_significant: bool (any test significant)
        - recommendation: str (actionable recommendation)
        - sample_size: int (number of runs)
        - metric: str (metric analyzed)

    - compare_hyperparameters(
        self,
        run_ids: List[str],
        metric: str = "val.rmse",
        top_n: int = 10
      ) -> pd.DataFrame
      Analyze hyperparameter correlations with performance:
      * Use self.comparator.compare_by_ids(run_ids) to fetch run data
      * Extract parameter columns: [c for c in df.columns if c.startswith('params.')]
      * Extract metric column: f'metrics.{metric}'
      * Compute correlations: df[param_cols + [metric_col]].corr()[metric_col]
      * Sort by absolute correlation (descending)
      * Select top_n hyperparameters
      * Return DataFrame with columns:
        - parameter: str (parameter name)
        - correlation: float (Pearson correlation with metric)
        - abs_correlation: float (absolute value for sorting)
        - direction: str ("positive" or "negative")
        - interpretation: str (e.g., "Higher learning rate correlates with better performance")

    - rank_experiments(
        self,
        run_ids: List[str],
        metrics: List[str] = ["val.rmse", "val.mae"],
        weights: Optional[List[float]] = None
      ) -> pd.DataFrame
      Rank experiments by multiple metrics:
      * Use self.comparator.compare_by_ids(run_ids) to fetch run data
      * If weights is None, use equal weights for all metrics
      * Normalize metrics to 0-1 scale (min-max normalization)
      * For loss metrics (rmse, mae): lower is better, use (1 - normalized)
      * Compute weighted score: sum(normalized_metric * weight for each metric)
      * Sort by score (descending)
      * Return DataFrame with columns:
        - run_id: str
        - score: float (weighted composite score)
        - rank: int (1 = best)
        - metrics: dict (individual metric values)
        - normalized_metrics: dict (normalized values)

      * Else: return "Strong correlation between {param_name} and {metric}"
