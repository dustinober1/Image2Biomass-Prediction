  <files>mlflow_tracking/analytics/interpretability.py</files>
  <action>
    Implement ModelInterpretability class in interpretability.py:

    - __init__(self, tracking_uri: Optional[str] = None)
      Initialize MLflow client for model loading

    - _load_model_from_artifacts(self, run_id: str)
      Load model from MLflow artifacts:
      * Fetch run using client.get_run(run_id)
      * Load model using mlflow.pyfunc.load_model(f"runs:/{run_id}/model")
      * Handle sklearn, xgboost, and pytorch models
      * Return loaded model object
      * Raise MlflowException if model artifact doesn't exist

    - _create_explainer(self, model, X_background: pd.DataFrame, model_type: str = None)
      Create appropriate SHAP explainer based on model type:
      * If model_type is "tree" or model has feature_importances_ attribute:
        - Use shap.TreeExplainer(model, data=X_background)
        - Optimal for XGBoost, RandomForest, GradientBoosting
      * If model_type is "linear" or model has coef_ attribute:
        - Use shap.LinearExplainer(model, X_background)
        - Optimal for Ridge, Lasso, LinearRegression
      * If model_type is "deep" or model is torch.nn.Module:
        - Use shap.DeepExplainer(model, X_background)
        - For PyTorch models (requires background data)
      * Default fallback: shap.KernelExplainer(model.predict, X_background)
        - Model-agnostic but slower
      * Return explainer object
      * Log explainer type as MLflow param for reproducibility

    - compute_shap(
        self,
        run_id: str,
        X_test: pd.DataFrame,
        background_samples: int = 100,
        model_type: str = None
      ) -> Tuple[np.ndarray, shap.Explainer]
      Compute SHAP values for model predictions:
      * Load model from MLflow artifacts using _load_model_from_artifacts()
      * Select background samples (random subset of X_test, size=background_samples)
      * Create explainer using _create_explainer()
      * Compute SHAP values: shap_values = explainer.shap_values(X_test)
      * Return (shap_values, explainer) tuple
      * Handle multi-output models (return list of SHAP arrays)
      * Raise ValueError if X_test is empty or background_samples > len(X_test)

    - plot_feature_importance(
        self,
        shap_values: np.ndarray,
        X_test: pd.DataFrame,
        feature_names: List[str] = None,
        plot_type: str = "summary",
        max_features: int = 20
      ) -> plt.Figure
      Create feature importance visualization:
      * If plot_type is "summary":
        - Use shap.summary_plot(shap_values, X_test, feature_names=feature_names, show=False)
        - Shows global feature importance with impact direction
      * If plot_type is "bar":
        - Use shap.summary_plot(shap_values, X_test, plot_type="bar", show=False)
        - Shows mean absolute SHAP values per feature
      * Limit to max_features top features (default 20)
      * Use feature_names from X_test.columns if not provided
      * Set title='Global Feature Importance (SHAP)'
      * Return matplotlib figure
      * Handle both single-output and multi-output SHAP values

    - plot_local_explanation(
        self,
        shap_values: np.ndarray,
        X_test: pd.DataFrame,
        sample_idx: int,
        feature_names: List[str] = None
      ) -> plt.Figure
      Create local explanation (waterfall plot) for single prediction:
      * Extract SHAP values for sample_idx: shap_values[sample_idx]
      * Extract feature values: X_test.iloc[sample_idx]
      * Use shap.waterfall_plot(shap.Explanation(values=shap_values[sample_idx], base_values=explainer.expected_value, data=X_test.iloc[sample_idx], feature_names=feature_names), show=False)
      * Set title=f'Local Explanation for Sample {sample_idx}'
      * Return matplotlib figure
      * Raise IndexError if sample_idx is out of range

    - plot_dependence(
        self,
        shap_values: np.ndarray,
        X_test: pd.DataFrame,
        feature_idx: int,
        feature_names: List[str] = None
      ) -> plt.Figure
      Create SHAP dependence plot for single feature:
      * Use shap.dependence_plot(feature_idx, shap_values, X_test, feature_names=feature_names, show=False)
      * Shows how feature value affects SHAP value (feature importance)
      * Colors by interaction feature (auto-selected by SHAP)
      * Set title=f'SHAP Dependence Plot: {feature_names[feature_idx]}'
      * Return matplotlib figure

    Follow SHAP best practices from research:
    - Choose explainer based on model type (don't use KernelExplainer for tree models)
    - Use background samples for DeepExplainer and KernelExplainer (computational efficiency)
    - Handle multi-output models (list of SHAP arrays for multi-target)
    - Log explainer type as MLflow param for reproducibility
